live-caption 1.1  桌面悬浮实时字幕（英文语音 → 中文字幕）

一、怎么用
1. 开始菜单或桌面启动 live-caption，屏幕上出现半透明字幕条（可拖动，拖边缘可改大小）。
2. 播放任何英文语音（线上会议、视频）：说话 0.3 秒后英文就开始出现，正在说的这句带淡黄底色高亮；说话过程中就有灰色的临时中文跟着出，停顿后英文定稿、中文整句重翻成白字。屏上已出现的文字只增不缩。
3. 鼠标悬停字幕条右上角有按钮：设置 / 收起 / 穿透 / 记录 / 透明度 / 字号 / 显示段数 / 暂停 / 退出。
4. 托盘图标（任务栏右下角）点开菜单：切回可点击 / 鼠标穿透 / 暂停继续 / 收起或展开 / 设置 / 打开记录 / 退出。
5. 全局热键（设置里可改）：Ctrl+Alt+C 切回可点击，Ctrl+Alt+P 切换鼠标穿透。
6. 无语音 20 秒后字幕条自动缩成小条，有语音自动展开；也可手动收起/展开。

二、翻译后端（设置窗"翻译"页，切换立即生效，有"测试翻译"按钮）
- Claude Code CLI（默认）：需要已安装并登录 claude 命令。安装包可代装，登录要自己跑一次 claude。
- Codex CLI：需要已安装并登录 codex 命令；每句起一个进程，较慢。
- OpenAI 兼容接口：DeepSeek、通义千问、自建网关、本地 Ollama 都行，填 Base URL、API Key、模型。

三、识别（设置窗"识别"页，改动需重启，有"保存并重启"）
- 最终句用 large-v3-turbo（最准），说话过程中的临时英文用 base.en（最快，英文落后语音约 0.25 秒）。两个模型随安装包一起装在 models\ 目录。

四、历史记录（设置窗"记录"页）
- 每次运行一个记录文件，逐句写入英文与中文；可预览、删除、清空、打开文件夹或用外部程序打开。

五、文件位置
- 程序与模型：安装目录（默认 D:\Program Files\live-caption）。
- 配置、字幕记录、日志：%APPDATA%\live-caption\（config.toml / transcripts\ / logs\）。
- 重装、升级或改安装目录（含"仅我用"/"所有用户"切换）都不会动这里的配置；模型路径随安装目录变了会在启动时自动修正。

六、依赖
- 显卡驱动自带的 Vulkan（识别用 GPU）；VC++ 运行库（安装包自动装）；中文字体用系统自带的微软雅黑。

七、隐私
- 会议音频不出本机；只有识别出的英文文本会送到你选的翻译后端。
