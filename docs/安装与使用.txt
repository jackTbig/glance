translate-tool 安装与使用
=========================

一、这是什么
------------
一个自用的翻译工具，桌面端 + Chrome 插件，翻译由大模型完成。
- 桌面端：在任意窗口里划词、悬停取词、框选屏幕区域翻译。
- Chrome 插件：整页双语对照、悬停翻段落、划词弹面板。
API Key 只存在本机的桌面端配置里，插件本身不存任何密钥。


二、安装
--------
1. 运行 translate-tool-setup-0.1.0.exe，按提示装完（默认装到 D:\Program Files\translate-tool）。
2. 装完会自动启动，托盘出现一个蓝色「译」图标。
3. 装 Chrome 插件：
   - 打开 Chrome，地址栏输入 chrome://extensions
   - 右上角打开「开发者模式」
   - 点「加载已解压的扩展程序」，选择 安装目录\extension 文件夹
   （开始菜单里有「浏览器插件目录」快捷方式可直接打开）


三、配置
--------
右键托盘图标 → 设置。首次启动会自动从 live-caption 借用已有的接口地址与 Key（如果装过）。
需要填的只有三项：接口地址、API Key、模型。默认是 DeepSeek。

- 接口地址：DeepSeek 填 https://api.deepseek.com
             通义千问填 https://dashscope.aliyuncs.com/compatible-mode/v1
- 每个场景（整页 / 划词 / 悬停 / 截屏）可以分别选后端。
  整页翻译固定走 OpenAI 兼容接口：claude 与 codex 是常驻子进程，撑不住几十路并发。
- 术语表：填「原文 → 固定译法」，命中的段落会把这条对照一起发给模型。

改完点「保存并应用」立即生效。改热键与服务端口需要重启应用。


四、桌面端怎么用
----------------
- 划词：选中文字，选区旁会弹一个小「译」按钮，点它出译文面板。
        也可以直接按 Ctrl+Alt+Y。小图标嫌烦可以在设置里关掉。
- 悬停：按住 Alt 把鼠标停在一段文字上约 0.3 秒，自动取词翻译。
        修饰键和延时都能改，选「关闭悬停」就不再触发。
- 截屏：按 Ctrl+Alt+G，屏幕变暗，拖出一个框，框里的文字会被识别并翻译。
        图片、视频字幕、扫描版 PDF 里的文字都能用这个。
- 面板上的图钉按钮可以钉住不自动关闭，钉住后可以拖动。

取词优先走系统的无障碍接口（快，毫秒级，能拿到整段）；拿不到时自动截图做文字识别。
在写代码的软件里不想被打扰，可以在设置里把进程名加进例外列表（默认已排除 VS Code、
Visual Studio、Windows Terminal）。


五、浏览器插件怎么用
--------------------
点插件图标弹出功能菜单，常用的都在里面：

- 顶部一行显示桌面端连没连上、用的哪个模型。
- 「翻译此页」大按钮：翻完变成「恢复原文」，下面出现「双语对照 / 仅译文」两个切换。
- 「段落翻译」格子：点一下开关。开着时把鼠标停在某段上、按住 Alt 约 0.3 秒，只翻那一段。
  格子里的「Alt」两个字可以点，循环换成 Ctrl 或 Shift。
  松开键再按住同一段，会撤掉这一段的译文；再来一次又翻回来。
- 「划词翻译」格子：点一下开关。开着时选中文字会在旁边弹「译」按钮。
- 右下角「本站停用」：在当前网站不弹图标、不响应悬停（快捷键仍然可用）。
- 左下角「设置」：端口、悬停延时、停用站点清单等更细的项。

不想开菜单也行，两个快捷键直接生效（菜单底部会显示当前是哪两个）：
- Alt+Shift+S 翻译选中的文字。
- Alt+Shift+Y 整页翻译，再按切「仅译文」，第三次回原文。

段落翻译不占组合键，直接按住 Alt（或你换的那个键）就行。

这两个键由插件在网页里自己监听，不是 Chrome 的扩展快捷键，所以：
- 不受 Chrome「一个扩展最多 4 个快捷键」的限制；
- 不会被 Alt+Shift+T 这类浏览器内置键抢走（那个键 Chrome 留给自己做工具栏焦点，扩展永远拿不到）；
- 想换成别的组合，在插件设置页的「快捷键」一栏直接改，保存即生效，不用刷新页面；
- 在输入框里打字时不会误触发。

段落翻译的用法：把鼠标停在要看的那一段上，按住 Alt 约 0.3 秒。
松开键、再按住同一段，就撤掉这一段的译文；再来一次又翻回来。
按住不放扫过多段时，每段各翻一次，不会重复翻同一段。

段落翻译永远是中英对照：原文留在原处，译文插在紧下方，
带一条蓝色竖线。即使整页切到了「仅译文」，这样单独翻的段落也仍然保留原文。
插件读的是网页里的文字本身，不做截图识别，所以链接、加粗这些格式都能保留。

菜单里改的开关立刻生效，不用刷新页面。

插件必须配合桌面端使用。桌面端没运行时，页面右下角会提示「翻译工具未运行」。

如果看到「插件刚更新过，请刷新页面」，是因为在 chrome://extensions 里刷新过插件，
而这个标签页还开着旧版脚本。按 F5 刷新即可。新打开的标签页不受影响。


六、已知限制
------------
1. 文字识别只装了简体中文语言包，识别英文时偶尔会多插空格或把 It 认成 lt。
   翻译时模型会自动纠正，一般不影响阅读。想要更准，用管理员权限运行：
       Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
   装完重启应用即可。
2. 划词时会临时占用剪贴板并在取词后还原。原剪贴板里如果是图片或文件，还原不回来。
3. 浏览器窗口里的桌面端悬停取词多半拿不到文字（浏览器不暴露无障碍文本），
   会退到截图识别。浏览器里请用插件，效果更好。
4. codex 后端在本机跑不通：codex CLI 的默认模型要求更新版本的 CLI。
   升级 codex CLI 后可用。日常用 DeepSeek 即可。
5. 全局快捷键可能被别的软件抢先占用。应用启动时会自动往下试备选组合，
   实际用的是哪一组，看设置窗顶部那行状态，或看日志里「热键 …」那一行。
   本机实测 Ctrl+Alt+T / S / X / D / W 与 Ctrl+Shift+D 都已被占用，所以默认用
   Ctrl+Alt+Y（划词）、Ctrl+Alt+G（截屏）、Ctrl+Alt+Q（面板开关）。


七、数据与隐私
--------------
- 配置与日志在 %APPDATA%\translate-tool\（开发目录下有 config.toml 时用开发目录）。
- 本地服务只监听 127.0.0.1，且只接受浏览器扩展发来的请求，网页直接调会被拒绝。
- 送去翻译的内容会发给你配置的那个模型服务商。机密页面请只用本机服务或可信的私有网关。
