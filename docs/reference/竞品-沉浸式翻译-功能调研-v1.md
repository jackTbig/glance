## 1. 整页翻译
- **模式**：默认双语对照（原文下方插译文）；「仅译文」在扩展面板 →「更多」→ 切换「仅译文模式」。（https://immersivetranslate.com/zh-Hans/docs/faq/ ）
- **触发方式**：点扩展图标 / 页面右侧悬浮球 / 右键菜单「翻译网页」/ 快捷键。默认 **Alt+A** 翻译与还原切换，**Alt+W** 翻译整页（区别于默认的「智能翻译」只译主内容区）；冲突可在「设置 → 界面设置 → 快捷键管理」改。（https://immersivetranslate.com/zh-Hans/docs/usage/ ；https://immersivetranslate.com/zh-Hans/docs/features/webpage/ ）
- **译文样式**：官方列有下划线、虚线、弱化/遮罩(mask)、高亮、马克笔、实线边框等主题，可改背景色、文字色、字号缩放；高级配置里可按站点用 `globalStyles` 覆盖样式。（https://immersivetranslate.com/zh-Hans/docs/advanced/ ；https://sspai.com/post/83943 ）
- **自动翻译规则**：可设「始终翻译某语言」「永不翻译某语言」、按网站白名单/黑名单自动翻译；高级配置支持按域名/URL 通配符/路径写规则，且**可按站点指定翻译服务**（例：某域名用 DeepL，其余用 Google）。关闭自动翻译在面板或设置页取消勾选。（https://immersivetranslate.com/zh-Hans/docs/advanced/ ；https://immersivetranslate.com/zh-Hans/docs/faq/ ）
- **文件与媒体**：PDF（`/docs/features/pdf/`）、EPUB（`/docs/features/epub/`）、字幕文件 .srt/.ass（`/docs/features/subtitles/`）、视频双语字幕 YouTube/Netflix/Bilibili 等（面板勾选「自动开启双语字幕」；`/docs/features/video-subtitles/`），Zoom/Meet/Teams 会议字幕；图片/漫画翻译为 Pro 功能。（https://immersivetranslate.com/zh-Hans/docs/usage/ ）

## 2. 鼠标悬停翻译
- **默认关闭**，需在扩展面板里启用。启用后**按住 Shift 同时把鼠标悬停在某段落**，该段落下方出现双语译文。（https://immersivetranslate.com/zh-Hans/docs/features/hover/ ）
- 触发键可改为 Ctrl/Alt/Shift 组合，或改为纯悬停无修饰键（防误触角度官方建议保留修饰键）。（https://sspai.com/post/83943 ）
- **粒度：段落**（官方文档措辞为「某个段落」），未提供句级悬停。
- FAQ 常见故障：页面须先获得焦点（先在页面任意处点一下）。（https://immersivetranslate.com/zh-Hans/docs/faq/ ）
- 输入框内悬停翻译：官方未说明（未查到）；输入框场景走第 3 节的「输入框增强」。
- 悬停能否单独指定翻译服务：官方文档**未查到**明确设置项；仅在「临时接入其他 AI 模型」文档里说 Ollama/Groq 等「主要推荐用于鼠标悬停和输入增强」，意味着这些服务在悬停场景更实用，但没有写「悬停独立选服务」。（https://immersivetranslate.com/zh-Hans/docs/services/ai/ ）

## 3. 划词翻译
- **准确说法**：官方**自带**划词翻译，**1.16.5（2025-04-22）** 起在 PC 端扩展上线（不含油猴脚本版），与 AI 术语库、OpenRouter 同批发布；此前只能用悬停段落替代。（https://immersivetranslate.com/en/docs/CHANGELOG/ ）
- **操作**：鼠标选中单词/短语后，把鼠标移到选区右下角出现的小圆点/logo 上（或按自定义快捷键），译文就地弹出不跳页。（官方博客 https://immersivetranslate.com/blog/select-and-translate-launch/ ，正文抓取失败，摘要来自搜索快照；https://zhuanlan.zhihu.com/p/1915657593122198757 ）
- **近期迭代**：1.17.4 支持 Pin 面板并查看历史；1.32.7 操作按钮始终可见；1.33.1 面板自适应尺寸、可拖拽调整、可切换「双语对照 / 仅译文」。（https://immersivetranslate.com/zh-Hans/docs/CHANGELOG/ ）
- 面板是否含词典释义/音标/例句/发音：社区导航站称「AI 翻译与发音，支持词组、音标、例句」，**官方文档未查到**逐项说明。划词能否单独指定翻译服务：**未查到**。
- **输入框翻译**（官方 `/docs/input/`）：任意输入框输入母语后**快速连按 3 次空格**即译成目标语言（0.6.2+）；前缀 `/en`、`/ja` 指定目标语言；`你好 //世界` 只译 `//` 之后部分；移动端用双击/三击/滑动等手势。设置项：默认目标语言、**翻译服务（可独立指定）**、分割字符、触发字符、间隔时间、网站黑名单。已知限制：地址栏不支持、Kiwi/飞书文档/Notion 有问题；Mac 需关闭「连按两下空格插入句号」。（https://immersivetranslate.com/zh-Hans/docs/input/ ；https://immersivetranslate.com/zh-Hans/docs/faq/ ；https://sspai.com/post/83943 ）

## 4. AI 模型后端
- **官方服务清单（AI 类）**：OpenAI（含 Azure OpenAI）、Claude、Gemini、DeepSeek、Kimi、智谱 GLM、通义 Qwen-MT、豆包、零一万物、OpenRouter、Ollama、Groq、Grok、腾讯云 TokenHub（1.32.10 新增）、以及「自定义接口」。（https://immersivetranslate.com/zh-Hans/docs/services/ ）时间线：1.5.7 支持 OpenAI 兼容自定义 AI 服务，1.6.1 DeepSeek，1.15.2 Grok/Ollama/Groq/Azure，1.19.6 豆包/Qwen-MT，**1.30.2（2026-06-10）自定义 API 按 Base URL 自动补全 OpenAI / Anthropic 接口路径**。（https://immersivetranslate.com/zh-Hans/docs/CHANGELOG/ ）
- **配置方式**（设置 → 翻译服务 → 选服务 → 展开「更多设置」）：API Key（多个 Key 用英文逗号分隔可负载均衡）、自定义接口地址（Azure 示例 `https://{name}.openai.azure.com/openai/deployments/{deployment}/chat/completions?api-version=...`）、模型下拉或自定义模型名。（https://immersivetranslate.com/zh-Hans/docs/services/openai/ ）
- **OpenAI 兼容第三方 / 本地模型**：选 OpenAI 或「自定义」服务，填 Key、模型名、接口地址即可。Ollama：`http://localhost:11434/v1/chat/completions`，Key 随意，需设 `OLLAMA_ORIGINS=*`（Windows 加环境变量 `OLLAMA_HOST=0.0.0.0`、`OLLAMA_ORIGINS=*`）；Groq：`https://api.groq.com/openai/v1/chat/completions`。（https://immersivetranslate.com/zh-Hans/docs/services/ai/ ；https://immersivetranslate.com/zh-Hans/docs/services/ollama/ ）
- **可调参数**：每次请求最大段落数（默认 3 段，多段用 `%%` 分隔合并请求）、每秒最大请求数（超限排队到下一秒；429 就调低，电子书场景尤其）、温度（temperature）、自定义请求 header/body、术语库、「严格遵循自定义提示词」模式（放宽译文 token 比例校验，用于非翻译任务）。（https://immersivetranslate.com/zh-Hans/docs/advanced/ ；https://immersivetranslate.com/zh-Hans/docs/services/openai/ ）并发上限是独立于 QPS 的社区诉求，官方仍只有 QPS（issue #2567）。
- **自定义 Prompt**：五类——`systemPrompt`（单段系统提示）、`prompt`（单段用户提示）、`multipleSystemPrompt/systemMultiplePrompt`（多段系统提示）、`multiplePrompt`（多段用户提示）、`subtitlePrompt`（字幕）。变量：`{{text}}`、`{{from}}`、`{{to}}`、`{{content_type}}`、`{{title_prompt}}`、`{{summary_prompt}}`、`{{terms_prompt}}`。复杂流程（如「反思翻译」两步）用 YAML 配置，入口「设置 → 开发者 → 编辑完整用户配置」。（https://immersivetranslate.com/zh-Hans/docs/prompts/ ）
- **AI 专家 / 术语库**：设置页有「AI 专家」Tab，本质是官方仓库里的 YAML prompt 预设（金融、技术文档、学术、文学等），可自建并 PR；AI 术语库 1.16.5 起支持预置领域库或自建，仅对 AI 服务生效。（https://github.com/immersive-translate/prompts ；https://immersivetranslate.com/en/docs/CHANGELOG/ ）
- **按场景分别指定服务**：**输入框翻译可独立选服务（已证实）**；**按网站可独立选服务（已证实，高级配置）**；悬停、划词是否可独立指定——官方文档**未查到**。
- **Pro 额度 vs 自定义 Key**：Pro 每月 2000 万 Token 基础额度，每月 1 日刷新、不累积（年费也按月发放）；另有 PDF Pro 每月 1000 页；顶级/高级模型加油包（GPT-5.6 Terra/Claude Sonnet 5/Gemini 3.1 Pro；GPT-5.6 Luna/GLM-4.7/Claude Haiku 4.5/DeepSeek-V4-Flash/Gemini 3 Flash/PLaMo 2.2 Prime/DeepL）仅 Pro 可购。自填 Key：扩展侧免费不限次，费用由服务商收取；2025-08 事件后官方承诺不限制第三方服务。各模型 Token 消耗倍率：**未查到**官方表。（https://immersivetranslate.com/zh-Hans/docs/faq/ ；https://immersivetranslate.com/zh-Hans/docs/subscription-quota/ ；https://immersivetranslate.com/en/topup/ ）

## 6. 使用建议（整页 + 悬停 + 划词，AI 后端）
1. **分场景配服务，优先利用已证实的两个独立开关**：整页翻译走全局默认服务；输入框翻译单独指定一个快模型；悬停/划词目前无独立选项，会跟随全局服务，所以全局服务应选「便宜且快」的模型，避免划一个词也走贵模型。
2. **模型分层**：整页阅读用 DeepSeek-V4-Flash / Gemini Flash / GLM 这类低价快模型即可（多段合并 3 段/请求，token 消耗主要在这里）；确需高质量的长文（论文、合同）临时切 Claude/GPT 顶级模型，或用「按网站指定服务」把特定域名固定到强模型。
3. **省额度**：关「自动翻译」只留按站点白名单；把「每次请求最大段落数」保持默认 3～5 段（合并太多段反而容易超长重试）；「每秒最大请求数」按服务商限速调低避免 429 重发；AI 术语库只在专业站点启用。
4. **自定义 OpenAI 兼容接口**：设置 → 翻译服务 → 选「OpenAI」或「自定义」→ 更多设置 → 填 Key、Base URL、模型名；1.30.2 起只填 Base URL 就会自动补 `/v1/chat/completions` 或 Anthropic 路径。本地 Ollama 记得设 `OLLAMA_ORIGINS=*`，接口填 `http://localhost:11434/v1/chat/completions`。多个 Key 逗号分隔可分流。
5. **Pro 还是自填 Key**：不想管 Key、月用量在 2000 万 Token 内 → Pro；已有中转/自建网关 → 免费版 + 自填 Key 完全够用，功能不缩水（划词、悬停、输入框均非 Pro 专属）。
6. **隐私**：若翻译内部文档，别用「分享快照」功能；敏感页面配合本地模型或 OneAIFW 脱敏。
