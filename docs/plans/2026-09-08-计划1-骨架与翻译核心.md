# 计划 1：仓库骨架 + 翻译核心 crate + live-caption 切换

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建好 Cargo workspace，把 live-caption 的三后端翻译代码抽成共享 crate `ai-translate`，补齐并发池、重试、批量、标签保护、术语表、场景 prompt，用假服务测过，并让 live-caption 切换依赖后回归通过。

**Architecture:** `ai-translate` 是阻塞式（reqwest blocking + std 线程）库：底层 `Engine` 封装三后端（系统提示改为参数），上层 `Translator` 按场景路由后端、限并发、批量打包、重试。假服务 `mock-llm` 同时是库（测试进程内起）和 bin（给后续 Playwright 用）。live-caption 只替换 `Engine` 与后端配置类型，字幕专用的线程与 prompt 留在原处。

**Tech Stack:** Rust 1.98、reqwest 0.12（blocking, rustls）、serde/serde_json、anyhow、tracing、axum 0.8 + tokio（仅 mock-llm）。

**依据：** `docs/design/2026-09-08-翻译工具-设计说明-v1.md` §3、§4、§9。
