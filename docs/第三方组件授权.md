写清来源、版本、授权与「我们改了什么」。

## 离线词典数据：ECDICT

- **来源**：<https://github.com/skywind3000/ECDICT>
- **版本**：2026-09-20 取自仓库 `master` 分支的 `ecdict.csv`（770,611 行）
- **授权**：MIT License（Copyright (c) 2017 Linwei）
- **我们做了什么**：只取 `word` / `phonetic` / `translation` / `exchange` 四列，
  丢掉英文释义与词频等用不上的列，编译成本程序的二进制词库 `dict\ecdict.bin`
  （768,757 条，29 MB）。**词库内容本身没有改动**，只是换了存储格式。
- **安装包里的位置**：`安装目录\dict\ecdict.bin`
- **重新生成**：
  ```bash
  curl -L -o ecdict.csv https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv
  cargo run --release -p offline-dict --bin build-dict -- ecdict.csv D:\DevCache\tt-dict\ecdict.bin
  ```

MIT 要求分发时保留版权与许可声明，所以这一段必须跟着安装包走，别在精简安装包时把它删掉。
