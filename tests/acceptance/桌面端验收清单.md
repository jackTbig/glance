# 桌面端手工验收清单 v0.1.0

桌面取词涉及真实窗口、鼠标与屏幕，自动化成本极高，改为逐条手工验收。
每条给出操作步骤与预期，逐条打勾。测试前请确认桌面端已启动（托盘有蓝色「译」图标）。

自动化已覆盖的部分不在此列：翻译核心、本地服务、文字识别引擎、浏览器插件（共 118 项自动测试）。

---

## 一、启动与基础

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| 1.1 | 双击 translate-tool.exe | 托盘出现蓝色「译」图标，桌面上看不到任何窗口 | ☐ |
| 1.2 | 左键或右键点托盘图标 | 弹出原生菜单：设置… / 暂停取词 / 退出 | ☐ |
| 1.3 | 菜单点「设置…」 | 弹出设置窗，顶部一行状态写明取词、识别语言、服务端口 | ☐ |
| 1.4 | 首次启动后看 `%APPDATA%\translate-tool\config.toml` | 文件存在；若装过 live-caption，接口地址与 Key 已自动填好 | ☐ |
| 1.5 | 菜单点「退出」 | 应用退出，托盘图标消失，任务管理器里没有 translate-tool.exe | ☐ |

| # | 操作 | 预期 | 结果 |
|---|---|---|---|

| 2.5 | 点面板右上角 ✕ | 面板关闭 | ☐ |
| 2.6 | 选中一段英文，按 Ctrl+Alt+T（不点小图标） | 直接弹出面板并翻译 | ☐ |
| 2.7 | 什么都不选，按 Ctrl+Alt+T | 面板显示「没有选中文字」，不报错 | ☐ |

| 2.10 | 设置里关掉「选中后弹小图标」，保存，再选中文字 | 不再出现小图标，但 Ctrl+Alt+T 仍然可用 | ☐ |

## 三、悬停翻译

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| 3.1 | 在记事本里按住 Alt，鼠标停在一行英文上约 0.3 秒 | 弹出面板，来源显示「无障碍接口」，给出译文 | ☐ |
